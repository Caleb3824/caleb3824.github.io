Welcome to the blog! Basically, I've decided to develop a game, and I wanted a place where I can post my updates and have them all be collected in one place.

I can't be bothered writing up a bunch of paragraphs, so here's some random dot points about the project:
- It'll be a 4 player action adventure game in a fantasy setting, probably similar to Zelda Four Swords Adventure in a lot of ways, but purely co-op and with more focus on exploration.
- The main inspiration is [Cat Quest 2](https://store.steampowered.com/app/914710/Cat_Quest_II/), which I played with my brother around Christmas time a few years ago.
- I'm planning to write the game engine from scratch in Rust. Overall, I don't mind if other people use LLMs to write code for their games (as long as it's properly disclosed), and honestly an LLM could probably do a much better job at it than me - but this game is a hobby project, so I want to do it all the old-fashioned way, even if it takes a lot longer. To continue in this vein: for the game code, I'm planning to stick to tools/packages from 2021-2022 or earlier, at least wherever it ends up being feasible and convenient enough.
- Over the last few years, I've written down a lot of ideas for the game (at least 50k words, although I'm not sure what percentage of these are actually good) so for a lot of aspects, especially the game's mechanics and overall structure, I have a fairly clear vision of how I want things to end up. It's mainly a question of whether I actually have the ability/time/energy to create it.
- I haven't decided on a graphical style yet - I'm leaning towards pixel art, but I'm open to other ideas. In the meantime I'm planning to just use placeholder graphics from various SNES games.
- I'm not sure how long development will take, but it's an ambitious project and I sleep a lot so it might be many years.

Anyway, for now I'm still working on basic engine stuff, so I probably won't have anything exciting to share for a bit.

Thanks for reading!
